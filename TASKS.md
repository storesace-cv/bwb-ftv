| Task                                   | Responsible agent      | Required inputs                                                                                           | Transformation steps                                                                        | Expected outputs                                                                 | Example                                                                                           |
|----------------------------------------|------------------------|-----------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------|
| Import base spreadsheets into the database | Data Import Agent      | `imports/Produtos_Base.xlsx`, `imports/FichasTecnicas_base.xlsx`, `imports/PreçosTaxas_base.xlsx`         | Validate spreadsheets, synchronize table schemas, upsert product and ingredient data        | Updated `databases/ftv.db` and archived files in `imports/history/`              | Run `python services/products.py` after placing `Produtos_Base.xlsx` in `imports/` to load records and archive the file |
| Align database schema with spreadsheet headers | Schema Maintenance Agent | Base Excel files in `imports/` and the current database schema                                            | Compare table columns with spreadsheet headers, add missing columns, recreate tables if necessary | Modified schema within `databases/ftv.db`                                      | Execute `python tools/cleanup_schema.py` when a new column appears in `FichasTecnicas_base.xlsx` |
| Apply SQL migrations for preparation tables | Migration Agent        | `data/migrations/preparacao.sql` and the target database                                                  | Execute migration scripts and verify required tables exist after migration                   | Database with new or updated preparation tables                                 | Run `python tools/run_migration_preparacao.py` to create the `preparacao` table                 |
| Create or restore database backups      | Backup Agent            | Current `databases/ftv.db` or files in `databases/backups/`                                               | Generate timestamped backups or restore the database from a selected backup                  | Backup copies or a restored database file                                        | Use `python data/backup.py --create` to save a backup, or `python data/backup.py --restore backups/<timestamp>.bak` to roll back |
