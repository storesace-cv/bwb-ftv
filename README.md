# bwb-ftv
Fichas Técnicas Valorizadas

## Prerequisites
- Python 3.8 or newer

## Setup
Install the required packages:

```bash
pip install -r requirements.txt
```

## Usage
Run the application:

### Linux / macOS

```bash
python3 bwb-fichas_tecnicas.py
```

### Windows

```cmd
python bwb-fichas_tecnicas.py
```

Or using the Python launcher:

```cmd
py bwb-fichas_tecnicas.py
```
