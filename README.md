# bwb-ftv
Fichas Técnicas Valorizadas

## Instalação

### Linux/macOS
```bash
pip install -r requirements.txt
```

### Windows (PowerShell)
```powershell
pip install -r requirements.txt
```

## Execução

### Linux/macOS
```bash
python bwb-fichas_tecnicas.py
```

### Windows (PowerShell)
```powershell
python bwb-fichas_tecnicas.py
```
