# bwb-ftv
Fichas Técnicas Valorizadas

## Pré-requisitos
- Python 3.8 ou superior
- pip

## Instalação
### Windows
```powershell
pip install -r requirements.txt
```

### macOS
```bash
pip3 install -r requirements.txt
```

## Execução
### Windows
```powershell
python bwb-fichas_tecnicas.py
```

### macOS
```bash
python3 bwb-fichas_tecnicas.py
```
